# WUTHERING HEIGHTS — 1주년 키비주얼 페이지

노랑 / 검정 / 오프화이트 편집 디자인 스타일의 1주년 기념 한 장짜리 웹페이지입니다.
그림 세 점이 순서대로 나타났다 사라지고, 마지막에 가운데 전신이 남습니다.

```
오른쪽 두상  나타남 → 사라짐
왼쪽  전신  나타남 → 사라짐
가운데 전신  나타남 → 그대로 유지
```

오른쪽 아래 `REPLAY` 버튼을 누르면 처음부터 다시 재생됩니다.

가운데 그림이 다 나타나면 화면 아래 가운데에 자막처럼 대사가 뜨고,
**그 그림 · 자막 · `ENTER` 버튼 아무거나 누를 수 있게** 됩니다.
누르면 1·2번 그림이 약 2.2초 동안 다시 나타났다가, 위아래 띠가 커튼처럼 닫히면서
`page2.html` 로 넘어갑니다. 넘어간 쪽에서는 같은 커튼이 열립니다.

## 2. 그림을 내 이미지로 바꾸기

지금 들어 있는 선화는 직접 그린 임시 그림입니다.
`images/` 폴더에 **아래 이름 그대로** 파일을 넣으면 자동으로 그 그림이 대신 보입니다.

| 파일 이름 | 어디에 쓰이나 | 권장 |
|---|---|---|
| `images/head.png` | 오른쪽 두상 | **적용 완료** (직접 그린 선화) |
| `images/body-left.png` | 왼쪽 전신 | **적용 완료** (직접 그린 선화) |
| `images/body-center.png` | 가운데 (마지막에 남는 그림) | **적용 완료** (직접 그린 선화) |

- 파일을 넣기만 하면 되고, 코드는 건드리지 않아도 됩니다.
- 파일이 없으면 원래 선화가 그대로 나옵니다.
- 그림이 너무 크거나 작으면 `css/style.css` 의 `.fig--head`, `.fig--left`, `.fig--center` 줄에서
  `height` 숫자를 키우거나 줄이면 됩니다.

## 3. 속도 바꾸기

`css/style.css` 맨 위 `:root` 안에 있습니다. 단위는 초(s)입니다.
**네 줄만 바꾸면 박자가 알아서 일정하게 맞춰집니다.** 등장 시각은 자동 계산이라 건드릴 필요 없습니다.

```css
--t0:      .85s;   /* 첫 그림(두상)이 나오기 시작하는 시각 */
--inDur:   .65s;   /* 나타나는 데 걸리는 시간 */
--outDur:  .50s;   /* 사라지는 데 걸리는 시간 */
--hold:   2.40s;   /* 다 보인 채로 머무는 시간 (그림마다 동일) */
--gap:     .35s;   /* 하나가 사라지고 다음이 나올 때까지의 빈 틈 (동일) */
```

- 전체를 **느리게** 하고 싶다 → `--hold` 를 키우세요 (예: `3.2s`)
- 그림 사이가 **답답하다 / 너무 빈다** → `--gap` 을 조절하세요
- 나타나고 사라지는 동작 자체를 부드럽게 → `--inDur`, `--outDur`

현재 값 기준 흐름:

| | 등장 | 머무름 | 퇴장 | 빈 틈 |
|---|---|---|---|---|
| 두상 | 0.85 → 1.50초 | 2.40초 | 3.90 → 4.40초 | 0.35초 |
| 왼쪽 전신 | 4.75 → 5.40초 | 2.40초 | 7.80 → 8.30초 | 0.35초 |
| 가운데 전신 | 8.65 → 9.30초 | 계속 유지 | — | — |

## 5. 클릭해서 넘어가는 동작

`js/main.js` 맨 위 세 줄에서 조절합니다.

```js
var NEXT_PAGE  = 'page2.html';   // 넘어갈 파일 이름
var OUTRO_HOLD = 2200;           // 1·2번 그림이 다시 보이는 시간(ms). 2000~3000 권장
var CURTAIN    = 550;            // 커튼이 닫히는 시간(ms)
```

`CURTAIN` 값을 바꿀 때는 `css/style.css` 의 `curtainIn` 애니메이션 시간(`.55s`)도
같이 맞춰주세요. 안 맞으면 커튼이 다 닫히기 전에 페이지가 넘어가거나, 닫힌 뒤
잠깐 멈춰 있게 됩니다.

### 두 번째 페이지

`page2.html` 은 포스터형 한 장 구성입니다.

```
┌──────────┬──────────────────────────────┐
│ 초록 띠   │  큰 제목 + 손글씨 겹침          │
│  1115    │  한 줄 문장                    │
│  이름들   │                              │
│          │        ← 여기가 비어 있습니다     │
│ One year │                    ┌────────┐ │
├──────────┤                    │ 그 림   │ │
│ 2        │                    └────────┘ │
└──────────┴──────────────────────────────┘
```

글자는 `content.js` 의 `p2` 로 시작하는 항목들에서 바꿉니다.

| 항목 | 자리 |
|---|---|
| `p2Badge` | 왼쪽 띠 맨 위 타원 안 숫자 |
| `p2Names` | 왼쪽 띠에 세로로 서는 이름들 |
| `p2Note` | 왼쪽 띠 아래쪽 작은 글자 |
| `p2Label` / `p2Number` | 왼쪽 아래 작은 제목과 큰 숫자 |
| `p2Title` | 오른쪽 큰 제목 (Holtwood One SC) |
| `p2Script` | 제목 위를 가로지르는 손글씨 (Rock Salt) |
| `p2Caption` | 제목 아래 한 줄 |
| `p2Credit` | 2페이지 그림 그려준 분 (맨 아래 띠) |

제목과 손글씨는 `page2.html` 의 `data-fit` 숫자(캔버스 기준 px)보다 넓어지면
자동으로 글자 크기가 줄어듭니다. 서체를 바꿔도 그림을 밀고 들어가지 않습니다.
더 크게/작게 쓰고 싶으면 그 숫자를 조절하세요.

가운데 본문 글은 `page2.html` 의 `<div class="p2letter">` 안에 있습니다.
문단 하나가 `<p> … </p>` 한 줄이고, 줄을 더 넣으면 문단이 늘어납니다.
칸보다 길면 그 안에서 스크롤되고, 아래쪽은 살짝 흐려져 더 있다는 걸 알립니다.
글자 크기·칸 위치는 `css/style.css` 의 `.p2letter` 에서 조절합니다.

그림은 `images/p2-figures.webp` 입니다. 바꾸려면 같은 이름으로 덮어쓰거나,
`page2.html` 의 `<img class="p2art" src="...">` 한 줄을 고치면 됩니다.
크기·위치는 `css/style.css` 의 `.p2art` 에서 조절합니다.

## 6. 색 바꾸기

`css/style.css` 맨 위 `:root` 안에서 한 번에 바뀝니다.

```css
--paper:#F2F1EB;      /* 배경 */
--ink:#1E282C;        /* 선과 글자 */
--blue:#9ABADB;       /* 포인트 1 — 위쪽 띠, 파란 세로 기둥, 설명 줄 */
--sage:#8FA98C;       /* 포인트 2 — 아래쪽 띠, 祝 뒤 네모, 문장 강조 */
--blue-deep:#5F86B2;  /* 오른쪽 두상 선 색 */
--sage-deep:#637F60;  /* 왼쪽 전신 선 색 */
```

그림 세 점은 일부러 톤을 다르게 두었습니다.
오른쪽 두상은 연한 블루, 왼쪽 전신은 세이지, **마지막에 남는 가운데 전신만 진한 먹색**이라
마지막 그림이 가장 또렷하게 보입니다. 셋 다 같은 색으로 하고 싶으면
`.fig--head`, `.fig--left` 줄의 `color:` 부분을 지우면 됩니다.
