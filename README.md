# WUTHERING HEIGHTS — 1주년 키비주얼 페이지

노랑 / 검정 / 오프화이트 편집 디자인 스타일의 1주년 기념 한 장짜리 웹페이지입니다.
그림 세 점이 순서대로 나타났다 사라지고, 마지막에 가운데 전신이 남습니다.

```
오른쪽 두상  나타남 → 사라짐
왼쪽  전신  나타남 → 사라짐
가운데 전신  나타남 → 그대로 유지
```

오른쪽 아래 `REPLAY` 버튼을 누르면 처음부터 다시 재생됩니다.

---

## 1. 글자 바꾸기

**`content.js`** 파일 하나만 열면 됩니다. 따옴표 `" "` 안쪽 글자만 고치세요.
따옴표와 쉼표는 지우면 안 됩니다.

| 항목 | 화면에서 보이는 곳 |
|---|---|
| `pageTitle` | 브라우저 탭 제목 |
| `topLeft` / `topRight` | 맨 위 노란 띠 좌 / 우 |
| `wordmarkLine1` / `wordmarkLine2` | 가운데 위 큰 로고 (두 줄) |
| `wordmarkSub` | 로고 아래 작은 글자 |
| `cap1~3` | 짧은 설명 줄 세 개 (왼쪽 위 · 왼쪽 아래 · 오른쪽) |
| `verticalLeft` / `verticalRight` | 세로로 누운 작은 글자 |
| `cornermark` | 오른쪽 위 구석 표식 |
| `bigNumber` | 왼쪽 아래 큰 숫자 |
| `lead` / `sub` | 오른쪽 아래 문장과 날짜 |
| `tagHead` / `tagLeft` / `tagCenter` | 그림마다 붙는 작은 꼬리표 |
| `marquee` | 맨 아래에서 흐르는 글자 |
| `credit` | 맨 아래 왼쪽 작은 글자 |

## 2. 그림을 내 이미지로 바꾸기

지금 들어 있는 선화는 직접 그린 임시 그림입니다.
`images/` 폴더에 **아래 이름 그대로** 파일을 넣으면 자동으로 그 그림이 대신 보입니다.

| 파일 이름 | 어디에 쓰이나 | 권장 |
|---|---|---|
| `images/head.png` | 오른쪽 두상 | **적용 완료** (직접 그린 선화) |
| `images/body-left.png` | 왼쪽 전신 | 배경 투명 PNG, 세로로 긴 비율 |
| `images/body-center.png` | 가운데 전신 (마지막에 남는 그림) | 배경 투명 PNG, 세로로 아주 긴 비율 |

- 파일을 넣기만 하면 되고, 코드는 건드리지 않아도 됩니다.
- 파일이 없으면 원래 선화가 그대로 나옵니다.
- 그림이 너무 크거나 작으면 `css/style.css` 의 `.fig--head`, `.fig--left`, `.fig--center` 줄에서
  `height` 숫자를 키우거나 줄이면 됩니다.

## 3. 속도 바꾸기

`css/style.css` 맨 위 `:root` 안에 있습니다. 단위는 초(s)입니다.
**네 줄만 바꾸면 박자가 알아서 일정하게 맞춰집니다.** 등장 시각은 자동 계산이라 건드릴 필요 없습니다.

```css
--t0:      .85s;   /* 첫 그림(두상)이 나오기 시작하는 시각 */
--inDur:   .65s;   /* 나타나는 데 걸리는 시간 */
--outDur:  .50s;   /* 사라지는 데 걸리는 시간 */
--hold:   2.40s;   /* 다 보인 채로 머무는 시간 (그림마다 동일) */
--gap:     .35s;   /* 하나가 사라지고 다음이 나올 때까지의 빈 틈 (동일) */
```

- 전체를 **느리게** 하고 싶다 → `--hold` 를 키우세요 (예: `3.2s`)
- 그림 사이가 **답답하다 / 너무 빈다** → `--gap` 을 조절하세요
- 나타나고 사라지는 동작 자체를 부드럽게 → `--inDur`, `--outDur`

현재 값 기준 흐름:

| | 등장 | 머무름 | 퇴장 | 빈 틈 |
|---|---|---|---|---|
| 두상 | 0.85 → 1.50초 | 2.40초 | 3.90 → 4.40초 | 0.35초 |
| 왼쪽 전신 | 4.75 → 5.40초 | 2.40초 | 7.80 → 8.30초 | 0.35초 |
| 가운데 전신 | 8.65 → 9.30초 | 계속 유지 | — | — |

## 4. 파일 구성

```
index.html       화면 구조 (선화 SVG가 안에 들어 있음)
content.js       ★ 글자는 여기서 바꿉니다
css/style.css    디자인과 애니메이션
js/main.js       글자 넣기 · 이미지 교체 · 화면 크기 맞추기 · 재생
images/          ★ 내 그림을 넣는 곳
figures/         선화 원본 SVG (참고용, 지워도 페이지는 돌아감)
```

## 5. 색 바꾸기

`css/style.css` 맨 위 `:root` 안에서 한 번에 바뀝니다.

```css
--paper:#F2F1EB;      /* 배경 */
--ink:#1E282C;        /* 선과 글자 */
--blue:#9ABADB;       /* 포인트 1 — 위쪽 띠, 파란 세로 기둥, 설명 줄 */
--sage:#8FA98C;       /* 포인트 2 — 아래쪽 띠, 祝 뒤 네모, 문장 강조 */
--blue-deep:#5F86B2;  /* 오른쪽 두상 선 색 */
--sage-deep:#637F60;  /* 왼쪽 전신 선 색 */
```

그림 세 점은 일부러 톤을 다르게 두었습니다.
오른쪽 두상은 연한 블루, 왼쪽 전신은 세이지, **마지막에 남는 가운데 전신만 진한 먹색**이라
마지막 그림이 가장 또렷하게 보입니다. 셋 다 같은 색으로 하고 싶으면
`.fig--head`, `.fig--left` 줄의 `color:` 부분을 지우면 됩니다.
